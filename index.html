Cloud Cost Estimator: compare AWS, Azure and Google Cloud costs

Cloud Cost Estimator is a free calculator that shows what a cloud architecture will cost before you build it. Drag services onto a canvas or import your Terraform, set sizes and run times, and see the cost of each service, the total, and the same design priced on AWS, Azure and Google Cloud. There's no sign-up, and it doesn't need access to your cloud account.

How it works

  1. Pick a cloud: AWS, Azure or Google Cloud. You can switch at any time without redrawing.
  2. Add services: drag them from the left panel, or click Import Terraform to build the diagram from your existing code.
  3. Configure each one: set the instance size, quantity, run time in hours, days or months, and usage such as GB stored or requests per month.
  4. Wire them together: each wire carries data transfer, so egress and cross-zone costs are counted.
  5. Read the estimate: see a breakdown by service group and the same diagram priced on all three clouds.

Estimate costs from Terraform

Add .tf and .tfvars files, a whole folder, or pasted code. The tool reads them in your browser, without uploading them, and builds an editable diagram with services, sizes, quantities and connections for AWS, Azure and Google Cloud. An import report lists what to check: usage amounts that are placeholders, sizes missing from the price list, and resources it couldn't price.
